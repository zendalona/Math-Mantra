# 📚 Math Mantra

Math Mantra is an open-source mathematics tutoring application designed to help students improve their problem-solving skills through interactive exercises and lessons.

## 🚀 Features

- 🧮 **Interactive Math Problems** – Solve questions with step-by-step guidance.
- 🎯 **Personalized Learning** – Adaptive difficulty levels based on user progress.
- 📊 **Performance Analytics** – Track progress and identify areas for improvement.
- 🌍 **Multilingual Support** – Supports multiple languages for wider accessibility.
- 📱 **Mobile & Web Support** – Responsive design for seamless learning.

## 📥 Installation & Setup

Clone the repository:
```sh
git clone https://github.com/your-username/MathMantra.git
cd MathMantra
```

Install dependencies:
```sh
pip install -r requirements.txt
```

Run the application:
```sh
python main.py
```
